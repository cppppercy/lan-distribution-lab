## 记录规则

- 本机多进程或本机 HTTP 测试只说明程序行为，不能标为真实多设备无线测试。
- 性能结论应保留原始 CSV/JSON、环境信息和至少三轮关键对照；未运行或失败的轮次同样记录。
- 不提交真实私人文件、访问令牌、Wi-Fi 密码或完整敏感日志。
